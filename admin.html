Akhmeteli Admin

Sign in with a GitHub access token to edit the shop. Changes are saved to your repository and the live site updates automatically.

How do I get a token?
  1. Open GitHub → Fine-grained tokens → Generate new.
  2. Under Repository access choose Only select repositories → akhmeteli-winery.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate, copy the token, and paste it above.
